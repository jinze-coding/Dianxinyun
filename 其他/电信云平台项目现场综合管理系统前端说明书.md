# 1. 项目概述

## 1.1 项目背景

原方案以“多页面展示型大屏”为主，核心偏向总览展示与三维可视化。
经最新沟通，本项目需求方向已调整为：

1. 不再采用三维模型作为中间主视觉。
2. 平台需支持多个项目统一管理，不是单一工地项目展示。
3. 摄像头实时视频接入成为本项目重点能力。
4. 系统不仅要展示，还要承载部分业务操作能力。
5. 原有部分系统保留，通过跳转或接入方式纳入统一平台。
6. 页面数量精简为 3 个核心页面。

## 1.2 项目目标

建设一个面向多项目现场的综合管理平台，实现以下目标：

- 实现多项目统一总览
- 实现海康摄像头实时视频接入与展示
- 接入原有人员管理系统
- 新建临时人员管理业务模块
- 实现安全三级教育资料上传与留档
- 接入塔吊等设备管理系统
- 实现资料上传、查询、归档等资料管理能力

## 1.3 产品定位

本系统定位为：

**“大屏总览 + 业务管理 + 第三方系统接入”的项目现场综合管理平台**

它既不是纯展示型大屏，也不是纯后台业务系统，而是兼顾展示、管理、跳转与接入的综合性平台。

# 4. 用户角色与权限建议

## 4.1 角色划分

### 平台管理员

负责系统配置、项目维护、账号权限、入口配置。

### 项目管理员

负责本项目资料上传、人员与安全数据维护、设备与监控查看。

### 安全管理员

负责安全三级教育记录、培训文件上传、证书资料管理。

### 监控/设备管理员

负责视频查看、设备状态查看、塔吊系统信息查看。

### 普通查看用户

仅查看概况、视频、统计信息，无编辑能力。

## 4.2 权限原则

- 页面查看权限按角色控制
- 上传、编辑、删除需单独授权
- 第三方系统跳转入口可按角色显示
- 项目数据按项目权限隔离

# 5. 业务流程说明

## 5.1 临时人员与安全教育流程

```text
临时人员登记
→ 人员信息录入
→ 进入安全三级教育
→ 上传培训资料/签字文件
→ 形成教育记录
→ 留档查询
```

## 5.2 资料流转流程

```text
资料产生
→ 上传资料
→ 资料分类
→ 状态标记
→ 查询查看
→ 留档归档
```

### 资料来源

- 安全三级教育培训资料
- 工人签字确认文件
- 施工日志
- 会议纪要
- 其他凭证/证明文件

### 资料状态建议

- 已上传
- 待确认
- 已归档

## 5.3 设备与监控流程

```text
项目切换
→ 加载项目视频资源
→ 展示实时视频窗口
→ 查看设备状态
→ 查看塔吊接入数据
→ 切换监控布局
```

# 14. 最终结论

本次系统不再按原 6 个展示页面设计，而是调整为 3 个核心页面：

## 1. 项目概况

负责项目总览、视频总览、原人员管理系统跳转、资料管理

## 2. 人员与安全

负责临时人员管理、安全三级教育、培训资料与签字文件上传

## 3. 设备与监控

负责海康实时视频、视频布局切换、塔吊系统接入、设备状态展示

这套结构更符合客户当前需求，也更适合作为后续 UI 设计与开发实施的基础版本。
