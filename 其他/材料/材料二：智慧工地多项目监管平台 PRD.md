# 智慧工地多项目监管平台 PRD

## V1.0 产品需求说明书

------

## 一、文档定位

本文档用于说明 **“智慧工地多项目监管平台 V1.0”** 的产品建设内容、功能范围、页面结构、数据要求、接口要求、视频接入要求及实施边界。

该平台作为建工后续智慧建造业务的软件底座，主要承接智慧建造战略中 **智慧化施工管理、项目现场可视化监管、视频监控接入、人员安全管理、设备管理、资料归档、多项目统一管理** 等内容。

根据《智建未来》PPT 中提出的方向，建工未来智慧建造业务重点包括智慧化施工管理、虚拟建造、智能装备运用等能力，其中智慧化施工管理强调对工地“人、机、料、法、环”的智能化管控，并包括人员车辆管理、安全环境监测、AI视频监控、机械可视化、材料管理和协同平台等内容。

因此，本平台 V1.0 重点先落地 **智慧工地多项目监管平台**，作为后续 BIM、数字孪生、智能装备、AI视频分析等能力扩展的基础。

------

# 二、项目背景

建工后续计划围绕智慧建造方向开展业务建设，需要将战略层面的“智慧建造”具体落到可运行、可展示、可管理、可复制的软件平台中。

当前建筑项目现场普遍存在以下问题：

1. 项目数量多，分布分散，缺少统一监管入口；
2. 工地视频、人员、安全、资料、设备数据分散在不同系统中；
3. 项目管理方难以及时掌握现场真实情况；
4. 施工现场视频接入、在线率、点位覆盖、存储周期等存在监管要求；
5. 人员安全教育、临时人员管理、签字资料和培训文件缺少统一留档；
6. 塔吊、摄像头、设备等现场资源缺少统一台账；
7. 后续 BIM、智能装备、数字孪生等能力缺少统一软件底座承接。

结合上海市施工现场视频监控管理要求，部分工程需将施工现场视频接入“上海市建筑工地安全监管平台”，基础点位应覆盖人员出入口、塔吊/制高点、基坑及危大工程作业区，并要求支持 GB/T28181-2016、H.264 编码、视频存储、设备在线率等要求。

# 三、产品定位

## 3.1 产品名称

**智慧工地多项目监管平台 V1.0**

## 3.2 产品定位

本平台定位为：

> 面向建工多项目现场管理的智慧工地综合监管平台，统一承载项目地图、项目概况、视频监控、摄像头资源、人员安全、资料归档、设备接入和多项目数据看板等能力。

## 3.3 平台价值

平台主要帮助建工实现：

1. 多项目统一地图化监管；
2. 项目现场视频集中查看；
3. 摄像头资源和国标设备 ID 管理；
4. 临时人员和安全三级教育管理；
5. 安全资料、签字文件、证书文件统一上传归档；
6. 塔吊、设备等现场资源接入与状态展示；
7. 项目现场监管数据沉淀；
8. 为后续 BIM、数字孪生、AI视频识别、智能装备接入预留接口。

# 四、建设目标

## 4.1 一期目标

V1.0 阶段以 **“能监管、能接入、能留档、能扩展”** 为目标。

具体包括：

1. 建立多项目基础信息库；
2. 实现百度地图项目定位；
3. 实现项目概况总览；
4. 实现摄像头资源档案管理；
5. 实现视频播放地址接入能力；
6. 支持 1 / 4 / 8 / 16 路视频窗口展示；
7. 实现临时人员管理；
8. 实现安全三级教育和培训资料上传；
9. 实现资料上传、查询、下载、归档；
10. 实现塔吊/设备基础信息管理；
11. 支持原有人员管理系统跳转接入；
12. 建立角色权限和项目权限体系。

## 4.2 二期扩展方向

V1.0 不直接承诺全部智慧建造能力，后续可扩展：

1. BIM 模型展示；
2. 数字孪生大屏；
3. AI 视频识别；
4. 视频告警事件；
5. 智能装备数据接入；
6. 机器人作业数据看板；
7. 进度质量预警；
8. VR 安全教育；
9. 施工过程数字测绘；
10. 4D 施工模拟。

# 五、总体页面结构

结合当前需求，平台 V1.0 建议采用 **3 个主页面 + 项目地图模块** 的结构。

```text
智慧工地多项目监管平台 V1.0
├── 1. 项目概况
│   ├── 项目基础信息
│   ├── 项目进度
│   ├── 视频总览
│   ├── 原人员管理系统入口
│   ├── 资料管理模块
│   └── 项目地图定位模块
│
├── 2. 人员与安全
│   ├── 临时人员管理
│   ├── 安全三级教育管理
│   ├── 培训资料上传
│   ├── 签字文件上传
│   └── 教育记录留档
│
└── 3. 设备与监控
    ├── 摄像头资源管理
    ├── 实时视频窗口展示
    ├── 视频布局切换
    ├── 塔吊系统接入
    ├── 设备状态管理
    └── 视频访问日志
```

顶部导航建议：

```text
[项目概况]   [人员与安全]   [设备与监控]
```

项目地图定位作为 **项目概况中的模块或子标签页**，不单独增加一级页面，避免页面数量过多。

### 6.2.1 功能定位

系统接入百度地图，用于展示多个项目的地图位置。用户点击左侧项目列表时，中间地图区域自动跳转到对应项目位置。

| 无定位提示       | 未配置经纬度项目不生成 Marker    |

### 6.2.3 地图数据字段

| 字段              | 说明              |
| ----------------- | ----------------- |

### 6.3.6 视频播放原则

平台后端不直接转发视频流。

正确方式：

```text
后端校验权限
→ 后端返回播放地址或播放令牌
→ 前端播放器直接从视频平台/流媒体服务拉流
```

禁止方式：

```text
摄像头视频流 → 业务后端 → 前端
```

原因是：多项目、多路视频并发情况下，业务后端不适合承载大量视频流量。

# 七、用户角色与权限

## 7.1 角色设计

| 角色         | 权限说明                         |
| ------------ | -------------------------------- |
| 平台管理员   | 管理全部项目、用户、权限、配置   |
| 项目管理员   | 管理授权项目的数据               |
| 安全管理员   | 管理临时人员、安全教育、资料上传 |
| 设备管理员   | 管理摄像头、视频、设备、塔吊     |
| 普通查看用户 | 查看授权项目，无编辑权限         |

## 7.2 权限控制原则

1. 用户只能查看授权项目；
2. 所有包含 projectId 的接口必须做项目权限校验；
3. 上传、删除、归档、编辑操作必须校验功能权限；
4. 视频播放地址获取必须校验项目权限；
5. 文件下载必须校验项目权限；
6. 外部系统入口可按角色显示。

# 十、视频接入专项要求

## 10.1 视频点位要求

基础点位建议至少覆盖：

```text
1. 工地人员出入口
2. 塔吊 / 制高点
3. 基坑及其他危大工程作业区
```

## 10.2 摄像头参数要求

建议在系统中记录并校验：

```text
GB/T28181-2016
H.264
1920x1080 或 1080x720 及以上
25fps
是否支持云台
是否支持巡航
是否支持夜视
存储天数 30 / 90
在线率不低于 80%
```

## 10.3 带宽估算

根据上传文件中的视频接入手册要求，可按：

```text
摄像头数量 × 4Mbps × 1.2
```

估算项目上行带宽需求。

示例：

```text
3 路摄像头 × 4Mbps × 1.2 = 14.4Mbps
建议不低于 15Mbps
```

## 10.4 视频流承载方式

平台后端只负责：

```text
摄像头资源管理
项目权限校验
播放地址获取
访问日志记录
```

视频流应由：

```text
海康平台
GB28181 平台
天翼视联
NVR
流媒体服务器
视频云服务
```

承载。

# 十六、验收标准

## 16.1 功能验收

```text
1. 用户可登录平台
2. 用户只能查看授权项目
3. 项目地图可展示项目点位
4. 点击项目可定位地图位置
5. 项目概况可展示基础数据
6. 摄像头资源可新增、编辑、查看
7. 视频播放地址接口可返回
8. 视频窗口支持 1/4/8/16 布局
9. 临时人员可新增、查询、编辑
10. 安全教育批次可创建和完成
11. 培训资料和签字文件可上传
12. 资料可查询、下载、归档
13. 设备和塔吊数据可展示或预留
14. 操作日志可记录关键行为
```

## 16.2 性能验收

```text
1. 支持 50 个以上项目数据管理
2. 地图点位加载不明显卡顿
3. 普通接口 1 秒内响应
4. 聚合接口 2 秒内响应
5. 视频播放地址 1 秒内返回
6. 文件上传失败有明确提示
7. 多项目切换数据正常
```

## 16.3 安全验收

```text
1. 未登录不能访问接口
2. 无项目权限不能查看项目数据
3. 无权限不能上传、删除、归档资料
4. 视频播放地址获取必须校验项目权限
5. 百度地图 AK、第三方密钥不得硬编码
```

# 十七、产品总结

**智慧工地多项目监管平台 V1.0** 是建工智慧建造业务的第一阶段软件底座。

它不直接承诺全部智能建造能力，而是优先解决最现实的项目监管问题：

```text
项目在哪里
现场怎么看
人员怎么管
安全资料怎么留
摄像头怎么接
设备状态怎么看
资料怎么归档
多个项目怎么统一监管
```

平台 V1.0 建成后，可作为建工后续智慧建造公司的基础产品雏形，并逐步扩展到 BIM、数字孪生、AI视频识别、智能装备接入等更高阶能力。
