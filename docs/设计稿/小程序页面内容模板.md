# 小程序页面内容模板

更新时间：2026-07-20。

配套图片：`docs/设计稿/小程序页面模板总览.png`。

五页优化预览：`docs/设计稿/小程序五页优化/总览.png`。

## 设计主题

- 背景：低饱和蓝灰 `#f4f7fb`。
- 卡片：白底、浅边框、8px 圆角、弱阴影。
- 主色：绿色 `#0f766e`，用于主按钮、已完成、正常状态。
- 辅助色：蓝色 `#1d4ed8`，用于信息类入口和次级操作。
- 警示色：琥珀色用于预警/待处理，红色用于异常/逾期。
- 信息密度：现场工具型页面，优先可扫读、可操作，不做营销式大面积视觉。

## 当前正式四栏设计

- 底部导航：资料、巡检、质量、我的。
- 登录默认进入资料管理；项目概况源码保留但不在正式路由和底栏显示。
- 资料、巡检、质量共享“当前施工区域”，底层继续使用 `projectId`。
- 资料页使用蓝灰辅助色，首屏展示区域、全部/使用中/已归档/近七日更新统计、上传、目录、回收站和资料列表。
- 资料列表支持一级目录、关键词、归档状态筛选和分页；详情展示属性、版本与操作记录，不再展示“资料类型”。
- 上传支持微信文件、拍照和相册；管理员可管理一级目录和回收站，移动端不提供批量操作。
- 质量页“质量资料”保持质量闭环附件口径，不与独立工程资料库自动合并。

| 页面 | 首屏内容 | 高频操作 |
| --- | --- | --- |
| 资料 | 区域选择、资料指标、上传入口、目录/筛选、资料列表 | 上传、预览下载、版本、目录、回收站 |
| 巡检 | 区域选择、应检/已检/未检、扫码、今日任务 | 扫码巡检、查看记录 |
| 质量 | 区域选择、质量指标、优先问题、状态筛选 | 发起检查、整改、复查、查看质量附件 |
| 我的 | 用户、角色、区域权限和账号服务 | 查看权限、个人信息、退出登录 |

## 历史五页设计

- 预览入口：`http://localhost:3003/#/pages/design-preview/index`。
- 五栏短名称：概况、人员、质量、安全、我的。
- 前四页共享“当前施工区域”，底层继续使用 `projectId`，不新增公司级项目层级。
- 当前为 V2 柔和专业版本：背景使用中性浅灰 `#F4F6F8`，内容主体使用柔白，模块采用浅色标题区与白色内容区的连接式结构。
- 页面辅助色分别为概况蓝灰 `#527AA3`、人员青绿 `#2F877B`、质量靛蓝 `#5B68A8`、安全琥珀 `#C07A32`、我的雾蓝 `#61778F`；绿/橙/红只用于业务状态。
- 模块统一 16rpx 圆角、控件 12rpx 圆角，列表通过留白、分隔线和状态标识组织，不使用卡片嵌套或密集硬边框。
- 底部使用半透明白色五栏导航和本地抗锯齿图标；活动入口显示对应页面淡色光晕。
- 页面切换、区域弹层、指标更新、分段筛选、列表入场、视频切换和扫码按压均提供克制动效，并支持 H5 减少动效模式。
- 概况保留单路视频预览，不在移动端复制 PC 四宫格监控墙。
- 安全页以扫码和当前角色任务为主；PC 的复杂权限、批量导入、改派和报表配置不搬到移动端。
- V2 五页方案及隔离预览页保留为历史设计对照，不代表当前正式路由。

| 页面 | 首屏内容 | 高频操作 |
| --- | --- | --- |
| 概况 | 区域选择、在场/摄像头/资料/进度、风险提醒、单路视频 | 切换摄像头、查看资料和异常设备 |
| 人员 | 区域选择、用工指标、人员分类、搜索、人员列表 | 新增人员、进退场、发起教育 |
| 质量 | 区域选择、质量指标、四个业务入口、优先问题列表 | 发起检查、整改、复查、查看资料 |
| 安全 | 区域选择、巡检指标、扫码入口、角色任务、三个快捷入口 | 扫码、电箱台账、检查记录、巡检汇总 |
| 我的 | 用户与角色、聚合待办、当前区域、账号与服务 | 查看待办、权限、个人信息和切换角色预览 |

## 页面模板

| 页面 | 核心内容 | 主要操作 |
| --- | --- | --- |
| 登录 | 平台名称、环境标签、账号、密码、错误提示 | 登录 |
| 项目 | 项目卡片、状态、阶段、电箱数、待办数、负责人 | 进入项目工作台 |
| 项目工作台 | 项目概况、纳管电箱数、待办数、六个业务入口 | 电箱台账、扫码巡检、复核、汇总、整改、待办 |
| 电箱台账 | 启用电箱、今日未检、搜索、状态筛选、电箱列表 | 查看电箱、进入详情 |
| 电箱详情 | 编号、位置、负责电工、安全负责人、二维码状态、公开码 | 开始日检、查看汇总 |
| 扫码 | 扫码框、最近扫码结果、手输编号入口 | 模拟扫码、手输编号 |
| 电箱日检 | 外观照片、内部照片、六项检查、异常说明、备注 | 提交复核 |
| 安全复核 | 待复核记录、照片数、异常数、检查项摘要 | 通过、退回、转整改 |
| 整改详情 | 问题、要求、责任人、期限、整改说明、整改照片 | 完成整改、复查关闭、退回 |
| 巡检汇总 | 月份、应检、已检、漏检、异常、未闭环、明细列表 | 导出月报、查看明细 |
| 我的待办 | 待巡检、待复核、待整改、待复查分组 | 进入对应处理页 |
| 我的 | 用户、角色、授权项目、设置入口 | 退出登录 |
| 外部扫码只读汇总 | 项目简称、电箱编号/位置、近 30 天汇总、异常和整改状态、脱敏提示 | 只读查看 |

## 脱敏规则

- 外部只读页不展示手机号、账号、内部用户 ID。
- 检查人只展示姓名或角色称呼。
- 整改详情只展示状态和摘要，不展示内部审批备注。
- 公开页不提供提交、复核、整改、导出等写操作。
