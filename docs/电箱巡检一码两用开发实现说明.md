# 电箱巡检一码两用开发实现说明

更新时间：2026-07-28（追加现行口径；主体实现记录形成于 2026-07-11）

> 当前身份口径（2026-07-28）：小程序工程已经创建；本期已实现小程序微信快捷登录、已有账号通过账号密码显式绑定、新账号注册审批后绑定，以及“小程序扫码确认—Web 登录”的快捷登录链路。手机号只用于注册核验或联系信息，不得以手机号相同为由自动匹配并绑定系统账号。正式环境必须使用正式 AppID/AppSecret、合法 HTTPS 域名，并设置 `VITE_USE_MOCK=false`、`WECHAT_MINI_PROGRAM_MOCK_ENABLED=false`。

> 历史说明：下文 2026-07-11 的微信手机号授权、mock 默认值和未完成事项按原样保留用于追溯；与本提示冲突时，以当前代码、2026-07-28 增量迁移和上述现行口径为准。

## 极简版当前口径

2026-07-11 起，本功能保留“一码两用”，但业务流已精简：

- 内部负责巡检员扫码后可进行今日巡检，项目领导可查看本箱记录，外部未登录用户只读月度公示。
- 新巡检直接归档为 `COMPLETED`，不再进入安全复核、现场抽查、整改或复查。
- 六项检查结果继续保留；照片、备注和异常说明均选填，异常只参与记录和月度统计。
- 小程序正式扫码动作只显示“今日巡检 / 本箱记录 / 月度公示”，不再提供演示身份切换和安全抽查。
- Web 统一码生成、打印、换码和公开访问开关继续保留。
- 微信订阅消息不再是本期巡检流程依赖；历史通知、复核和整改数据不删除，但当前产品不展示。

> 下文关于复核、抽查、整改和通知的内容是此前完整方案的实现记录，不再代表当前产品流程。

## 已落地范围

- 每个电箱以 `B:<publicCode>` 作为统一场景码，二维码本身不携带用户、项目权限或内部 ID。
- 可选登录的统一扫码解析接口根据 token、项目授权、巡检权限、负责电工关系、电箱状态和当日日检范围返回可执行动作。
- 外部人员无需登录，可查看最近 12 个月逐日《电箱检查记录表》；页面无编辑、审批和导出入口。
- 电箱日检范围使用历史区间表保存，改变当前范围不会重写历史月份的应检口径。
- 项目巡检设置支持日检截止时间、提前提醒分钟数、复核时限和整改自然日天数，默认值分别为 18:00、60、24、3。
- 安全员现场抽查一次提交直接生成整改任务，默认截止到生成日后第三个自然日；不再经过安全复核。
- 微信登录支持 `wx.login`、手机号授权、已有账号匹配、无项目权限申请、无账号注册申请和后台审批绑定。
- Web 电箱台账改为单个统一巡检码预览/打印/换码，并提供纳入或移出日检操作。
- 小程序新增统一扫码动作页、微信内部人员绑定页和公开逐日月表页。
- 巡检首页已使用统一扫码启动方法：微信开发者工具 mock 播放扫码动画后自动匹配待检电箱，H5 mock 自动模拟识别，微信真机调用 `uni.scanCode`；旧独立扫码页已删除。
- 扫码结果、日检、安全抽查、本箱记录、电箱台账和巡检汇总已统一为暖白、紧凑和轻量动效界面；本箱记录已按 `boxId` 筛选，mock 汇总不请求真实后端。

## 环境与迁移

目标数据库只执行增量脚本：

`backend/src/main/resources/sql/migrations/20260711_electric_box_unified_flow.sql`

禁止用 `init.sql` 代替增量迁移。正式微信能力需配置：

- `WECHAT_MINI_PROGRAM_APP_ID`
- `WECHAT_MINI_PROGRAM_APP_SECRET`
- `WECHAT_MINI_PROGRAM_MOCK_ENABLED=false`
- 合法 HTTPS request/upload/download 域名

当前 `touristappid` 或 mock 模式下，后端生成开发预览二维码；正式 AppID 配置完成后仍需把统一码图片生成切换为微信 `getUnlimitedQRCode` 并真机验收。

## 兼容策略

- 旧内部二维码解析、旧公开近 30 天汇总接口和字段暂时保留。
- 新贴纸只打印统一场景码。
- 换统一码后旧 `publicCode` 无法解析，操作写入二维码日志。
- 写操作始终由后端重新校验，公开码仅用于定位电箱。

## 本地演示与测试数据

2026-07-11 已补充两套演示数据：

- 小程序 `.env` 默认启用 `VITE_USE_MOCK=true`，包含负责电工、安全员、外部检查三种模拟扫码身份，以及待巡检、待复核、整改中、待复查、复查退回和已关闭状态。
- 切换真实接口可执行 `npm run dev:h5:real`，配置来自 `.env.real`。
- 本地数据库演示脚本：`backend/src/main/resources/sql/migrations/20260711_electric_box_demo_data.sql`。
- 本地 `dianxinyun` 已执行一码两用结构迁移和演示数据脚本；目标环境仍需按需单独执行。

开发二维码现在编码 H5 扫码动作页地址。当 `WECHAT_MINI_PROGRAM_PUBLIC_FALLBACK_URL` 保持默认 `localhost:3003` 时，后端会自动将其换成当前电脑的局域网 IPv4；手机需与电脑在同一网络，并通过 `scripts/dev-services.sh start/restart` 保持 3003 端口的真实接口 H5 预览运行。如已有固定局域网或公网 HTTPS 地址，仍可显式设置 `WECHAT_MINI_PROGRAM_PUBLIC_FALLBACK_URL`。配置正式 AppID/AppSecret 且关闭 mock 后，后端改用微信 `getUnlimitedQRCode` 生成正式小程序码。

Web 预览抽屉会将后端返回的 SVG 归一化为图片源后再渲染，不得使用原始 `dangerouslySetInnerHTML` 直接展示带固定尺寸的 SVG。小程序电箱详情不再绘制装饰性二维码；真实可扫码只从 Web 后台统一码接口生成。
