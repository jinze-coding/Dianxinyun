# 项目总览

更新时间：2026-07-28。

本文档只描述当前正式代码范围。历史地图、人员、摄像头、设备等已隐藏功能不作为当前产品入口，也不纳入本期菜单权限目录。

## 系统定位

电信云平台项目现场综合管理系统是一个多项目 Web 与微信小程序协同平台，当前正式业务范围为：

- 工程资料：一级目录、文件版本、预览下载、归档和回收站。
- 电箱巡检：电箱台账、每日巡检、记录查询、月表和统一二维码。
- 质量管理：问题发起、整改、复查和操作留痕。
- 系统管理：注册审核、用户、角色权限、菜单功能、项目授权、微信绑定和操作日志。

Web 与小程序共用 Spring Boot 后端、MySQL、Redis 和文件存储。前端只负责入口和按钮显隐，后端始终按操作权限码及具体项目范围执行授权。

## 客户端

| 客户端 | 目录 | 当前入口 |
| --- | --- | --- |
| Web | `frontend` | 账号密码登录、微信扫码登录、注册申请、申请状态；登录后进入首个有权业务页面 |
| 微信小程序/H5 | `wechat-miniprogram/site-platform-miniprogram` | 账号密码、微信快捷登录、注册申请、Web 登录确认；权限驱动自定义导航 |
| 后端 | `backend` | `/api/v1` 统一接口、JWT/Redis 会话、RBAC、项目数据隔离和审计 |

## 账号、注册与登录

新用户不能直接创建 `sys_user`，必须通过 Web 或小程序写入独立的
`registration_application`。申请状态固定为
`PENDING / APPROVED / REJECTED / CANCELLED`：

```text
提交申请
→ 待审批账号、手机号和微信身份并发占用
→ 平台审核
→ 事务内创建用户、分配平台角色/项目角色/项目范围
→ 小程序申请按微信身份自动绑定
→ 清除申请表密码摘要
```

Web 申请使用图形验证码，手机号首版由管理员人工核验；申请状态只能使用随机查询令牌查询或取消。密码使用 BCrypt，非 BCrypt 历史凭证禁止登录并标记为待重置。系统不提供默认测试账号。

微信快捷登录遵循同一 AppID 下用户、OpenID、UnionID 有效绑定一对一：

- 小程序未绑定微信时，只能使用账号密码显式绑定已有账号或提交注册申请。
- 手机号相同不能自动绑定。
- 已启用密码登录的用户重新验证密码后可自行解绑；仅微信登录账号由平台管理员处理。
- Web 扫码登录使用 2 分钟 Redis challenge，小程序必须确认；浏览器使用私有校验密钥和一次性交换码换取普通 JWT。

正式环境必须配置真实 AppID、AppSecret、合法 HTTPS 域名并关闭 mock。微信 mock 仅允许显式 `dev/local/test` Profile。

## 权限模型

权限结果由四部分共同决定：

```text
平台角色
+ 当前项目的项目角色
+ 角色菜单
+ 操作权限码
+ ACTIVE 项目成员范围
```

`GET /api/v1/auth/user-info` 返回菜单树、平台权限码和各项目上下文。平台级系统管理接口只认可平台角色权限；项目角色的权限只在对应有效项目内生效。平台管理员可管理完整系统目录，项目管理员只能管理已授权项目的成员、项目角色和项目访问申请。

菜单和操作权限是两个独立条件：菜单决定入口是否可见，操作权限决定页面内动作，后端接口仍作最终校验。详细规则见 `docs/权限规则.md`。

## 数据与迁移

已有数据库只能按 `docs/数据库结构.md` 执行增量迁移，不能执行包含
`DROP TABLE` 的 `backend/src/main/resources/sql/init.sql`。

统一注册/RBAC 使用：

```text
backend/src/main/resources/sql/migrations/20260728_unified_registration_rbac_wechat_login.sql
```

该迁移新增 6 张表，并通过 `sys_data_migration` 记录一次性权限种子。重复执行只补结构和缺失字典，不应恢复管理员已经停用的菜单或撤销的角色关联。正式本地 `dianxinyun` 在应用前必须备份；当前验证使用隔离数据库副本。

## 本地开发

优先使用：

```bash
./scripts/dev-services.sh start
```

脚本显式启用 `local` Profile 和微信 mock，并继续使用真实后端数据。手动启动、管理员密码恢复和正式微信配置见 `backend/README.md`。

## 验收边界

每次认证/RBAC 变更至少验证：

- BCrypt 正误、停用/待重置账号和全会话失效。
- Web/小程序注册、审批事务、取消、重复与并发占用。
- 微信唯一绑定、显式绑定、解绑、小程序快捷登录。
- Web 扫码确认、取消、过期、跨浏览器、重复消费和账号停用。
- 菜单可见性、操作权限、A/B 项目隔离和受保护接口 HTTP `403`。
- Web 构建，小程序类型检查、H5 与微信构建。
- 正式 AppID/AppSecret、HTTPS 域名和微信真机最终验收。
