# 项目总览

## 系统名称

电信云平台项目现场综合管理系统。

## 系统定位

本系统是面向多个建设项目现场的综合管理平台，定位为：

```text
多项目地图总览 + 项目现场业务管理 + 视频/设备接入 + 第三方系统入口
```

它不是纯展示大屏，也不是完整 ERP 后台。当前目标是用一个统一入口管理多个项目的现场信息、临时人员、安全教育资料、摄像头和设备状态。

## 业务背景

现有需求文档说明，项目方向已经从“多页面展示型大屏 / 三维模型主视觉”调整为：

- 不做三维模型作为主视觉。
- 支持多个项目统一管理。
- 摄像头实时视频接入是重点能力之一。
- 平台需要承载部分业务操作，而不是只展示。
- 原有人员管理、塔吊、设备等系统通过跳转或接口接入方式纳入统一平台。
- 本期以 3 个核心页面为主：项目概况、人员与安全、设备与监控。

当前代码又新增了地图总览能力，进入系统后默认显示 `MapDashboard`，用于项目列表、地图定位、项目跳转。

## 使用对象

根据需求文档和当前角色表，目标用户包括：

- 平台管理员：维护项目、系统配置、项目定位、账号和权限。
- 项目管理员：管理自己项目的数据、定位、资料、人员、安全教育、监控资源。
- 安全管理员：负责临时人员安全三级教育、培训资料、签字文件、证书留档。
- 监控/设备管理员：查看摄像头、设备状态和塔吊等设备信息。
- 普通查看用户：查看项目概况、视频、资料和统计信息。

注意：当前代码只部分实现这些角色能力。完整角色菜单和操作权限仍待开发。

## 核心业务流程

### 登录与进入系统

```text
登录页
→ 调用 /api/v1/auth/login
→ 前端保存 site_platform_token 和 site_platform_user
→ 进入地图总览
→ 拉取当前用户可访问项目
```

### 项目地图总览流程

```text
进入地图总览
→ 加载百度地图 AK
→ 调用项目列表
→ 按项目经纬度生成 Marker
→ 点击项目或 Marker
→ 打开项目信息窗口
→ 跳转项目概况 / 人员与安全 / 设备与监控
```

### 项目概况流程

```text
选择项目
→ 展示项目基础信息和进度
→ 拉取摄像头列表用于视频总览
→ 拉取文件资料列表
→ 支持资料上传、预览、下载、归档、删除
→ 支持进入镜头管理页面配置视频窗口
```

### 临时人员与安全教育流程

```text
登记临时人员
→ 人员状态初始为待教育
→ 创建安全教育批次
→ 关联待教育人员
→ 上传培训附件
→ 标记培训完成
→ 关联人员状态应变更为已教育
→ 资料留档查询
```

注意：当前前端“标记完成”主要更新本地状态，后端已有 `PUT /api/v1/safety-education/{id}/complete`，但前端当前函数未调用该接口，属于待修复项。

### 设备与监控流程

```text
选择项目
→ 拉取摄像头列表
→ 拉取设备列表
→ 展示在线/离线摄像头与视频占位窗口
→ 展示设备状态和塔吊数量
→ 支持新增、编辑、删除摄像头
→ 支持进入镜头管理页配置窗口布局
```

注意：当前系统还没有真正接入海康视频流或流媒体播放，视频区域是占位展示。

## 当前系统已经实现的能力

后端已实现：

- 登录、JWT 生成、用户信息、登出。
- 项目列表、项目详情、项目地图点位、项目地图详情。
- 项目定位更新，包含经纬度范围和坐标系校验。
- 项目新增、更新、删除。
- 临时人员列表、详情、新增、更新、删除、批量状态更新。
- 安全教育批次列表、详情、新增、更新、完成、删除。
- 文件列表、详情、上传、下载、更新、状态更新、删除。
- 摄像头列表、详情、新增、更新、删除。
- 设备列表、详情、塔吊列表、新增、更新、删除。
- 操作日志实体和 mapper，项目定位更新会写入操作日志。

前端已实现：

- 登录页。
- 地图总览页，使用百度地图 API GL。
- 项目列表、项目搜索、项目定位编辑、项目新增/编辑/删除入口。
- 项目概况页，展示项目信息、摄像头总览、资料管理。
- 人员与安全页，展示人员、安全教育、附件上传和培训记录。
- 设备与监控页，展示摄像头、设备、视频占位窗口和摄像头 CRUD。
- 镜头管理页，支持窗口布局和摄像头分配的前端状态。
- axios 统一 token 注入和错误处理。

数据库已具备：

- 项目、用户、角色、用户角色、用户项目权限。
- 临时人员、安全教育批次、安全教育人员关联。
- 文件资料、摄像头资源、视频布局配置、设备信息、设备状态记录。
- 视频访问日志、操作日志、外部系统配置。

## 后续计划开发的能力

从需求文档和当前代码缺口看，后续建议按以下顺序推进：

1. 修复前端当前运行时问题，例如 `OverviewPage` 中 `setSelectedCameras` 未定义。
2. 补齐后端项目权限：人员、安全、文件、摄像头、设备接口都必须按当前用户可访问项目校验。
3. 让 `ProjectPermissionService.getUserProjects` 真正查询 `sys_user_project`。
4. 统一状态字典：当前数据库种子数据使用英文状态，前端多处使用中文状态。
5. 完善密码校验，当前 `AuthService` 是开发期简化逻辑，README 的 `123456` 与实际可用 `admin123` 不一致。
6. 视频布局配置持久化到 `video_layout_config`。
7. 真实接入摄像头视频流或视频网关。
8. 摄像头资源字段增强，参考 `摄像头资源管理字段增强.md`。
9. 外部系统入口和塔吊系统接入。
10. 建立数据库迁移体系，避免继续依赖会清表的 `init.sql`。
11. 建立前后端自动化测试。
