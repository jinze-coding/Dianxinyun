# 单次预约访客导航弹窗

更新：2026-09-11。仅调整 `pages/public/visitor-invite`，不改后端接口、数据库、登记流程或会议资料。

## 页面

单次预约待填写页及有效放行回执在原信息卡片下方展示全宽“访客导航”按钮。点击后打开当前页居中弹窗，复用 `MeetingServiceDialog` 的宽度 92%、可用区域高度 85%、固定标题与关闭按钮、独立内容滚动和安全区。页面保留原来访信息、项目信息与表单，不增加会议字段或会议资料入口；错误传入 MEETING 邀请时不渲染会议记录。

弹窗内复用 `ProjectLocationCard` 的地图、地址、路线图和百度优先导航。地图仅在弹窗可见、页面在前台、邀请核验有效时挂载；路线图首次打开才下载。路线图失败仍可使用地图。关闭按钮、遮罩及返回操作均可关闭弹窗，保留未提交人员/车辆/备注和底层页面滚动位置。原生地图/大图返回恢复弹窗滚动，隐藏期间保留已下载图片供原生查看使用。

## 有效性与资源

继续使用公开邀请解析及路线图接口，令牌只在请求体传输。仅 PENDING、SUBMITTED 且未到计划离场时间、后端仍提供 projectLocation 时显示导航入口。打开及回前台重新核验，弹窗可见时每 30 秒核验；过期、作废、失权或导航撤下时卸载地图、关闭弹窗。网络故障在弹窗内提示重试并保留表单。

关闭、隐藏和卸载会使进行中的核验/路线图响应失效；迟到下载文件立即清理，不能重开地图或覆盖新状态。关闭和卸载清理已下载路线图，不读取访客当前位置，不扩大既有公开信息范围。
