# 单次预约访客导航弹窗

更新：2026-09-14。当前导航组件由单次预约与会议预约共用；本次仅调整小程序展示和地图调起，不改后端接口、数据库、登记规则或会议资料权限。

## 入口与展示

单次预约待填写页及有效放行回执在原信息卡下方展示全宽“访客导航”。会议预约及有效回执并排展示等宽“访客导航 / 会议资料”。入口统一实心蓝色、白色加粗文字、本地导航/资料图标及箭头，最小高度 48px；单次页面不展示会议字段或资料入口，错误传入 MEETING 时不渲染会议记录。

复用 MeetingServiceDialog 同页居中弹窗：宽度 92%，导航栏和安全区之外可用高度的 85%，固定标题和关闭按钮，内部独立滚动。正文依次显示地址、上传路线图、简短到访说明及四个地图入口。删除第一张在线地图、GCJ-02 标记、百度优先按钮及其说明。

路线图使用 widthFix 保持原比例，点击调用原生图片预览；缺失时显示简短说明。下载失败或图片解码失败均可重试，重试先复核邀请，再走原下载接口。无图或图片失败不禁用有效坐标导航；没有有效坐标时仍能查看图片，四个地图按钮禁用并显示原因。图标均为随包提供的原创本地 PNG 示意图，不请求外部图标资源。

## 地图选择与兼容

两行两列按腾讯、高德、百度、第四项排列，不默认选中。iOS 第四项为苹果地图；安卓、DevTools 与无法识别的平台为系统地图。

projectMapNavigation 接受 tencent / amap / baidu / apple / system。前四项向 MapContext.openMapApp 传所选 preferApplication；系统地图直接 uni.openLocation。使用服务端 GCJ02 坐标，不读取访客当前位置，不使用地图 AK。

微信接口仅接收推荐软件，可能仍展示原生选择面板，不能承诺强制直达。定义来源：[微信官方 API 类型](https://raw.githubusercontent.com/wechat-miniprogram/api-typings/master/types/wx/lib.wx.api.d.ts)。

组件只为 MapContext 保留绝对定位 1px、透明、无触摸响应、不占布局的 map 桥接；仅在弹窗有效且前台时存在。DevTools 的 openMapApp 空实现不返回回调，按能力不可用处理。缺失能力、异常或调起失败显示“返回改选 / 系统地图”确认；明确确认后才调起系统地图，取消安静结束。原生接口返回取消也不报错、不回退。调起与确认期间锁定全部地图入口；重复原生回调只接受第一次，关闭、失效、卸载或坐标变化后的迟到确认不打开地图。

## 有效性与资源

继续使用原公开邀请解析及路线图接口，令牌只在请求体传输。单次仅 PENDING 或有效 SUBMITTED、后端仍提供 projectLocation 时显示导航。会议沿用原开放/回执规则，会议结束关闭导航而保留公开资料，作废或失权关闭对外内容。

打开及回前台重新核验，弹窗可见时每 30 秒核验；过期、作废、失权或导航撤下时卸载地图并关闭导航。网络故障提示重试并保留登记草稿。关闭按钮、遮罩和返回均保留人员/车辆/备注及底层页面位置；原生地图或图片返回恢复弹窗滚动。

关闭、隐藏和卸载使未完成请求失效，迟到图片立即清理。原生图片查看期间保留临时文件；单次关闭/卸载清理，会议沿用原图片替换、到期及卸载清理规则。
