## 第一步：上传后只读核对

用户先上传外层 `.tar.gz` 和同名 `.sha256` 到服务器新建目录，反馈实际上传路径。根据该路径给出验包、解压与只读检查命令。核验外层 SHA-256 后解压，再在包根目录执行：

```bash
sha256sum -c SHA256SUMS
bash ops/preflight-readonly.sh
```

检查只输出服务状态、路径、文件摘要、依赖、磁盘、健康结果和数据库表名/迁移标记，不输出密码或业务记录，不停止服务、不执行迁移。MySQL 本机认证不可用时会明确提示；根据反馈补充只读连接方式，不要求在聊天里发送密码或环境文件。
