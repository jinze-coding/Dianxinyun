# 微信身份自动填写与入场页面修正

更新日期：2026-09-11。以本专题和当前代码为准，替代此前“仅同项目、首次单独勾选记住”的规则。

## 行为与边界

单次预约、会议预约、门卫登记、会议现场补录签到四个入口，按同一 AppID 和微信身份跨项目自动填写
本人单位、姓名、手机号码、出行方式、车牌。有历史信息即预填，无历史信息手工填写；同行人员每次填写。
小程序移除常用资料的列表、选择、命名、保存、更新、停用及记住开关。原隐私确认继续必填，说明本人信息
在成功提交后保存，用于本小程序后续跨项目扫码自动填写。原命名资料 API 与 Web 历史管理保留。

访客必须核对后提交；失败保留输入，不更新本人信息。四个入口共用 `useVisitorPersonalInfo`，只填尚未编辑
字段，主动清空也视为编辑；车辆切换保留已输入车牌，非驾车提交仍不带车牌。异步微信识别失败可重试，
页面卸载后迟到的身份/邀请响应不能恢复页面或覆盖输入。同行人员和原预约人员始终使用本次业务口径。

跨项目复用只提供本人五项字段，不返回来源项目、历史会议、同行人或他项目放行信息。当前项目、二维码、
短会话及业务用途仍逐次校验。过期登记可提供本人信息，但绝不恢复预约、门卫放行或签到资格；作废会议仍不可签到。
已有会议预约签到只显示原预约人员供逐人确认，不用跨项目本人资料替换预约名单。

## 历史查询与事务

`SiteVisitorPersonalProfileMapper.selectLatestPersonalInfo` 分别从四类来源选取最新候选，再按成功时间倒序取一份完整本人信息，
时间相同按本人快捷信息、单次、会议、门卫及记录 ID 排序，不按字段拼凑不同记录：

| 来源 | 限制 |
| --- | --- |
| 本人快捷信息 | 同 AppID、personal-profile 身份；未删除、有提交时间和加密手机号；不以 remember_enabled 过滤 |
| 单次预约 | 同 AppID、single-registration 身份；SINGLE/SUBMITTED、未删除、有提交时间 |
| 会议预约或微信现场补录 | 同 AppID、meeting-registration 身份；REGISTERED、未删除，父邀请 MEETING/OPEN 且未删除 |
| 门卫登记 | 同 AppID、guard-registration 身份；REGISTERED、未删除、有提交时间 |

以上来源的原项目均不得已删除；不检查历史时段是否结束。无可靠微信绑定、作废、删除、工作人员代录的业务
不进入补充来源。四类均无数据时，才查询同 AppID 与原身份摘要的 ACTIVE 命名资料，按最近使用/创建时间取一份。
禁止按手机号认领或保存明文 OpenID；身份 HMAC 用途保持独立，手机号及审计快照使用原 AES-GCM 服务。

四类成功提交在原业务事务内调用 `saveOnSubmission`，在本次项目保存本人快照及 AUTO_SAVE 加密审计。
旧 `rememberInfo` 可省略/为 false，不再控制保存；旧关闭记录可通过可靠历史业务重新带入。
每条本人快照仍归属提交项目，项目锁与原唯一键防止同项目并发覆盖；查询按微秒提交时间比较跨项目新旧。
任何业务、本人快照或审计写入失败均回滚。重试路径在保存前返回已有结果：

- 单次只向绑定的原微信返回原回执，其他微信 403；旧无微信归属单次仍 409。回执按当前状态显示过期。
- 会议预约和补录沿用每身份一组登记的行锁及唯一约束；重复/并发命中已有记录时不保存旧请求。
- 门卫重复且未新增会议关联时不保存本人信息；新增会议预约及关联成功时随本次信息保存。

## 接口和页面

接口沿用 `/api/v1/public/site-access`：单次 `visitor-sessions`、会议 `meeting/session`、门卫 `guard/session`，
以及 `meeting-check-in/session` 的 WALK_IN_FORM 均返回统一 `personalInfo`（available、兼容 rememberInfo、五项本人字段）。
`X-Visitor-Session` 仍在请求头，邀请令牌仍在请求体；当前二维码场景和身份摘要不跨用途混用。
旧命名资料接口保留兼容，小程序四页不再调用。请求体限制、受信 IP/身份限流和项目校验保持。

`publicVisitorForms.css` 统一全宽单列输入、88rpx 且至少 44px 的原生输入高度、纯水平内边距和占位文字样式；
出行按钮等宽圆角、统一字号，备注至少 90px。顶部导航固定，AppNavBar 沿用状态栏与微信胶囊尺寸，底部保留安全区。
门卫会议仍每 15 秒及恢复前台刷新，保持未变更选择，变更/结束/作废后提示重新核对。

实际包核对发现 uni-app 未输出外链 `style src` 的共享样式；四页改为在 scoped 样式中 `@import`。
新增 `verify:visitor-forms` 构建检查，直接校验四页生成的 WXSS/WXML 中原生输入高度、内边距、
出行按钮及固定导航的样式和作用域。微信普通构建和真实模式构建均执行此检查，dev 包另行校验。
