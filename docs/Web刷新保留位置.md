# Web 刷新保留位置

## 2026-09-15 当前规则

用户在浏览器刷新 `localhost:3002` 后，继续停留在当前选择的项目和页面。账号密码/微信扫码新登录仍进入个人待办；显式会议大屏 URL 及原返回上下文继续优先处理。

恢复范围包括五个正式业务模块、个人待办、系统管理、项目信息；保留资料管理专区及用印子页签、图纸收发页签、电箱/临边专区及子页签、质量页签、系统管理页签、场内分类、个人消息分类。会议完整详情保存会议 ID 和页签，安委会详情保存当前记录 ID，通过现有详情接口重新鉴权并核对项目后获取记录；记录已删除时返回列表。未保存编辑表单、上传文件、一般弹窗、列表筛选和滚动位置不加入本次导航存储。

## 实现与边界

- `frontend/src/utils/browserNavigation.js` 管理版本化导航标识；键为 `site_platform_tab_navigation`，使用标签页独立的 `sessionStorage`，记录绑定当前账号 ID。不同标签页可保持不同项目和页面。
- `App.jsx` 等账号、首次改密状态和项目列表全部成功确认后才恢复导航并挂载业务页面，避免临时空列表触发守卫回待办或覆盖保存的位置。项目请求用序号和会话凭证屏蔽退出后的迟到响应。网络加载失败保留位置供重试。
- 只接受正式页面；原项目被删除/移出范围时回到可访问项目和个人待办，原页面失权或模块关闭时保留有效项目并回个人待办。子页面仍执行原菜单和操作检查；存储的 ID 不替代后端鉴权。
- `BrowserNavigation` 提供页签恢复，按账号、项目及页面区分组件状态。退出、会话失效和首次改密时清理导航；浏览器禁止存储时正常导航仍可用。
- 只改 Web 及文档，无数据库迁移、后端接口、小程序、正式业务数据或角色授权变更。不提交 Git 或发布微信版本。
