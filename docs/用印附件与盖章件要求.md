# 用印附件与盖章件要求

更新日期：2026-09-11。以当前代码、接口和迁移为准。

## 业务规则

| 环节 | 当前行为 |
| --- | --- |
| 发起申请 | 用印事由及至少一项文件名称、份数仍必填；待盖章附件选填，无附件可提交审批。 |
| 已选择附件 | 继续执行原文件格式、大小、文件头和权限校验；小程序上传失败时保留草稿和所选文件，不能静默忽略后提交。 |
| 同意审批 | 项目经理审批意见窗口提供“要求上传盖章件”，默认不勾选，由本单当前指派审批人选择。 |
| 要求回传 | 批准后显示“用印后须上传”和“待上传”；上传后显示已上传数量。 |
| 按需回传 | 批准后可以自愿上传盖章件，无文件时显示按需上传。 |
| 驳回、复制 | 驳回不设置回传要求；复制不复制附件或审批要求，新草稿默认按需上传。 |

该选择与审批结果在同一事务和申请版本条件更新中保存。多人候选审批仍以首个有效决定为准，
不会增加印章保管人、实际盖章确认或二次审批节点。申请批准后状态仍为 `APPROVED`，
“待上传”是回传状态提示；文件上传和工程资料归档继续是批准后的独立动作。

项目经理是界面中的业务称谓，执行资格仍取当前有效审批任务，不能从角色名称推导。
申请人不能在创建、编辑或复制时设置最终回传要求。回传开关不会授予上传、删除、归档或项目查询权限。

## 接口和展示

`POST /api/v1/seal/applications/{id}/approve` 请求示例：

```json
{
  "opinion": "同意用印，请用印后补传盖章件。",
  "stampedResultRequired": true
}
```

`opinion` 保持必填。`stampedResultRequired` 省略、null 或 false 均为按需上传，兼容旧客户端；
驳回接口不采纳该字段。申请响应返回同名布尔值，Web 和小程序保持相同语义。

- 详情展示要求和上传数量，批准前提示可由审批人选择。
- 申请单 PDF 在审批意见区域追加回传要求，不改写原审批意见。
- 台账 Excel 的“盖章件上传状态”区分“待上传（审批要求）”“按需上传（未上传）”和“已上传 N 份”。
- 审批操作描述和申请人的现有站内审批通知包含回传要求；没有增加外部消息通道。
