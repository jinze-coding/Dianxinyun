# 小程序协议自主同意

更新日期：2026-09-15。针对“默认自动同意《用户服务协议》及《隐私政策》”的审核退回修复。修复前登录页仅有“登录或注册即表示同意”说明，未提供选择与协议详情；本次移除该表述。

## 用户流程

- 登录、微信快捷登录、注册、绑定页提供默认未勾选的协议控件。打开协议、阅读返回、切换登录/注册方式都不代为选择；重新进入页面默认未选，页面内明确选择可在阅读返回时保留，用户可以取消。选择不存入持久缓存。
- 《用户服务协议》新增公开只读页，说明实际服务范围、账号、资料、业务留痕、用户选择与联系项目管理员的方式。未登录和首次改密阶段也可以阅读，不返回任何业务数据或扩大权限。
- 《隐私政策》打开当前 AppID 在微信平台配置的《隐私保护指引》。失败显示提示；H5 提示在微信小程序内查看，不伪造平台协议或把提示视为授权。
- 未勾选时，密码登录、微信登录、注册及绑定事件处理直接返回；微信快捷注册原生手机号按钮禁用且无 `getPhoneNumber` open-type。勾选后仍由微信自身要求隐私授权；拒绝时不调用后续身份、登录或提交接口。
- 四种已有访客登记/签到入口本来就是默认未勾选并在提交前验证，保留原业务隐私告知和后端同意校验。正常已有会话恢复、角色/项目访问、首次改密、扫码续跳和业务数据不变。
