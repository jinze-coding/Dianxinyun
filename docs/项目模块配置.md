## 业务规则与操作入口

平台管理员在 Web「系统管理 → 项目模块」按项目名称或简称查询，在「配置模块」弹窗勾选、全选、清空并保存。允许全部关闭。五项固定业务模块为：

| 编码 | 名称 | 控制范围 |
| --- | --- | --- |
| SITE_ACCESS | 场内管理 | 内部管理、访客预约、门卫登记、会议签到及会议资料 |
| DOCUMENT | 资料管理 | 工程资料、用印、图纸收发与签收 |
| INSPECTION | 巡检管理 | 电箱及固定临边巡检 |
| QUALITY | 质量周检 | 周检、质量问题、整改复查及质量资料 |
| SAFETY_COMMITTEE | 安委会巡检 | 巡检记录、上传及媒体/文档读取 |

已有项目和新建项目默认全部启用。本次原本地三个实际项目仍为全部启用，包括北蔡测试0913；管理员后续自行配置。隔离验证库的开关变化不代表原库配置。

项目设置是业务访问的必要条件，对平台管理员同样生效。关闭只暂停目标项目对应业务，不改变共享角色菜单、操作权限、项目成员、历史数据、附件、负责人、已读状态或截止时间。重新启用后按原授权恢复，二维码、上传会话及导出文件沿用原有效期，不延期。

系统管理、项目列表、项目信息和小程序「我的」属于基础能力，全部业务模块关闭后仍可访问；个人待办显示由独立的入口开关控制。项目模块页面及写接口仅认可 `PLATFORM_ADMIN`，不新增可由普通项目角色代替的平台权限码。

## 接口与并发

接口统一使用原 JWT，会话不因修改项目开关而全量注销。

| 方法与路径 | 规则 |
| --- | --- |
| GET /api/v1/system/project-modules | 管理员分页；keyword 匹配项目名/简称，pageNo 默认 1、pageSize 默认 20、最大 100 |
| PUT /api/v1/system/project-modules/{projectId} | 管理员；提交 moduleCodes（0～5 个不重复正式编码）和 expectedVersion |
| GET /api/v1/projects/{projectId}/business-modules | 有效项目成员或平台管理员读取状态 |

状态返回 `projectId / enabledBusinessModules / moduleConfigVersion`；管理列表额外返回 `projectName / shortName`。`/auth/user-info` 的项目上下文带同一状态和版本，项目 `menuCodes / permissionCodes / businessModuleCodes` 已按项目开关与原角色规则求交集。全局目录不能用来恢复某项目的空菜单。

保存锁定目标项目，校验版本，并在同一事务更新五行与 `UPDATE_PROJECT_MODULES` 操作日志。日志记录前后模块集合及版本；审计失败整体回滚。相同选择不改变版本。版本冲突返回 HTTP 409，Web 保留当前勾选，点击「重新核对最新配置」读取最新版本、展示已保存集合后再确认保存；不会自动覆盖用户选择。

未启用模块返回真实 HTTP 403，响应 data 包含 `reason=PROJECT_MODULE_DISABLED`、真实项目和模块。配置缺行或版本不一致返回 503，不能默认放行。非法模块集合返回 400。

## 后端边界与两端同步

- 先校验目标项目模块，再执行原项目范围、角色操作权限、记录 ACL、上传归属及业务状态判断。平台管理员可免成员关系，但不能绕过项目开关；用印申请人、当前审批人、抄送人的原参与人规则继续保留。
- 无项目参数的业务列表、统计、个人待办、抄送、通知和角标按「真实项目＋模块」过滤。对停用通知批量标已读时跳过隐藏记录，重新启用仍按原未读状态恢复。
- 列表、详情、修改、业务硬删除预览/执行、上传续传、附件读取/下载、导出文件读取、视频 Range 都重新校验。通用文件入口按业务类型映射模块，不能换用通用接口绕过。
- 访客邀请、门卫、会议签到/资料、电箱公开码、用印码及图纸签收在解析实际业务项目后校验开关。匿名访问不借用角色开关，但仍受项目是否启用限制。基础项目图片不因此删除。
- Web 和小程序可见时每 5 秒核验当前项目配置，切换项目、恢复前台及恢复网络立即核验。变化后刷新统一用户信息、导航和待办；当前业务失效时取消相关请求、上传及下载，关闭业务页面并回当前项目可用页面（待办隐藏时按顶部规则回退），不注销其他项目会话。
- 客户端忽略旧项目、后台及已退出会话的迟到响应；小程序恢复前台还刷新全部项目上下文，避免其他项目重新启用后仍沿用缓存。网络失败保留最后成功状态并自动重试，实际业务始终以后端即时鉴权为准。
- 小程序自绘底栏按当前项目保留可用入口，原生五 tab 不变；安委会日期筛选仍只在 Web，移动端不携带隐藏日期条件。

## 后台任务与恢复边界

关闭期间停止临边周期任务生成及质量、电箱、临边提醒。首次初始化 `activated_at` 为空，兼容原周期；只有管理员从关闭改为启用时写入北京时间的重新启用时刻。恢复生成取原规则边界和此时刻的较晚者，停用期间及恢复前已经开始的周期不补建、不补提醒；已有任务不移动日期、不清责任人。

图纸逾期提醒也跳过停用项目和重新启用前已到期的记录。原提醒记录不删除，不恢复历史外部消息 Outbox。

质量/临边/用印导出以及安委会/会议资料预览转换，在领取时排除停用项目，执行与发布前重新校验。运行中遇到模块停用回到待处理，清理本次临时输出，不按转换失败消耗重试次数；重新启用后仍有效的任务继续处理。原过期清理保持，不延长文件或会话有效期。
