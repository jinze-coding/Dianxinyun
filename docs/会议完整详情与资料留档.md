# 会议完整详情与资料留档

更新：2026-09-11。范围为 `MEETING` 会议邀请，直接使用现有本地开发库、8080、3002 和小程序开发版；不复制到工程资料库。

## 页面与资料生命周期

会议详情在系统主内容区展开，沿用白色、蓝色主题，默认进入会场签到。顶部汇总会议资料和预约/签到人数，下方为预约登记、会场签到、会议资料、操作记录四个页签。名单随页面滚动，取消抽屉及固定高度，操作列粘在右侧。返回列表保留项目、日期、筛选、页码和滚动位置；从详情打开大屏时，将会议和页签放入当前浏览器的受用户/项目/时效约束的返回上下文。普通登录仍进入个人待办。

资料分类固定为宣发通知、议程课件、会议纪要、现场影像、其他。多文件分别留档，同名不覆盖。资料元信息与文件版本分开，更新文件须携带 `expectedVersion`，以会议行锁、资料行锁和版本唯一索引防止覆盖。新资料和新版本默认内部可见；上传新版本时旧公开版继续可见，明确发布最新版本才替换旧公开版。切为内部、撤下或发布新版后，旧公开地址不能再读取。已经下载到设备的副本无法远程收回。

会议结束后可继续上传、更新、预览、下载和发布资料。作废会议只允许内部留档，不对外返回资料。撤下保留全部版本和审计；永久删除复用平台管理员影响预览和一次性确认令牌。会议资料属于会议，删除会议同时清理这些版本、任务、原文件和预览副本；项目存在会议档案时禁止直接删除。

## 接口与权限

接口前缀均为 `/api/v1`，JSON 使用 `Result<T>`，文件响应使用流和 Range。

| 方法与路径 | 作用 |
| --- | --- |
| GET `/site-access/invitations/{id}/materials` | 名称搜索、分类/状态筛选、20 条分页 |
| GET `/site-access/invitations/{id}/materials/activities` | 最近 200 条会议操作，包含登记、签到及资料审计 |
| PUT `/site-access/materials/{id}` | 修改标题、分类、说明，校验 `expectedVersion` |
| PUT `/site-access/materials/{id}/publication` | 发布最新版本或切为内部，校验 `expectedVersion` |
| PUT `/site-access/materials/{id}/state` | 撤下/恢复，恢复不自动重新公开 |
| GET `/site-access/materials/{id}/versions` | 不可变版本历史 |
| GET `/site-access/material-versions/{id}` | 版本、文件及预览状态 |
| POST `/site-access/material-versions/{id}/preview-retry` | 失败重试或重新生成 Office/音视频/HEIF 预览 |
| POST `/site-access/material-versions/{id}/read-session` | 建立短期 HttpOnly 文件读取 Cookie |
| GET/HEAD `/site-access/material-versions/{id}/content?preview=true` | 预览副本；false 为原文件下载 |
| POST `/site-access/invitations/{id}/material-uploads` | 初始化分片上传 |
| GET/DELETE `…/material-uploads/{sessionId}` | 查询已上传分片/取消未完成上传 |
| PUT `…/material-uploads/{sessionId}/chunks/{index}` | multipart 分片和 SHA-256 |
| POST `…/material-uploads/{sessionId}/complete` | 合并、校验并原子留档，可安全重试 |
| POST `/public/site-access/meeting/materials/resolve` | 请求体提交 `inviteToken`，读取公开资料，允许会议已结束 |
| GET/HEAD `/public/site-access/meeting/materials/content/{publicCode}` | 可转发的不透明资源地址，每次重新检查发布/会议/项目状态 |

内部读取、预览、原文件下载使用目标项目 `SITE_ACCESS + site_access.view`，所有修改和上传使用 `site_access.manage`，人员导出仍使用 `site_access.export`。角色不新增。后端按记录真实项目鉴权，不能借前端项目参数跨项目；通用 `/files` 不得读写、换绑或枚举会议附件。

内部 Cookie 有效 15 分钟、SameSite=Strict、HttpOnly、HTTPS 下 Secure，路径精确到版本 content。Redis 只保存读取许可及加密的原登录凭证，每次读取仍验证原登录会话和当前项目权限。开发代理同时支持 `/api` 与 `/api/v1`，文件地址固定使用后者，确保 Cookie 作用路径一致。JWT、邀请码、访客会话不进入 URL。公开地址只含随机版本资源编号，返回 `private, no-store`、`nosniff`、`no-referrer`；公开解析和文件读取分别执行可信客户端 IP 限流。

## 分片、存储和转换

会议资料单文件 1GiB（1073741824 字节），分片 8MiB，会话 24 小时，续传绑定上传人和会议。Web 按块计算 SHA-256，不将整份大文件读入内存；服务端校验每片摘要、完整大小/摘要、扩展名/文件头及 Office 容器结构。其他模块上传额度保持不变。服务端 Redis 锁保护分片与完成，上传键唯一索引保证重复完成不会增加版本。

原文件使用 `MEETING_MATERIAL`，转换副本使用 `MEETING_MATERIAL_PREVIEW`。新增物理文件在事务回滚时清理；版本、文件元数据、当前指针、预览任务和会议审计在同一事务落库。删除先标记 `PENDING_DELETE`，提交后清理，失败保留 `DELETE_FAILED`。分片暂存每小时检查过期，预览工作目录每小时清理已无有效租约的遗留项。

预览状态：QUEUED、PROCESSING、READY、FAILED。PDF、图片、文本直接展示；Office 转 PDF，视频转 H.264/AAC MP4，音频转 MP3，HEIF 转 JPEG；CAD、压缩包等只提供原文件下载。转换失败不影响原文件下载，可由管理人员重试。重新生成只替换预览副本，不产生新的原文件版本。

转换使用独立单线程调度器和数据库租约，常规站内提醒及清理调度不会被转换阻塞。全局 `APP_SCHEDULING_ENABLED=false` 仍能关闭离线维护环境的所有调度。转换窗口最长 30 分钟，超时终止进程；租约 35 分钟，重复中断三次进入失败。每次使用独立工作目录和 LibreOffice 用户配置，输出再次校验格式。

命令参考：[LibreOffice 启动参数](https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html)中的 `--headless --convert-to pdf --outdir` 与独立 `UserInstallation`；音视频使用 [FFmpeg 文档](https://ffmpeg.org/ffmpeg.html)中的明确流选择和编码参数。

### 本地 macOS

`MEETING_MATERIAL_CONVERTER` 默认为 `../scripts/meeting-material-convert.sh`（后端工作目录）。脚本自动转到本地 macOS 转换器，可通过 `MEETING_SOFFICE_BIN`、`MEETING_FFMPEG_BIN` 指定实际二进制。当前本机已验证 LibreOffice headless 和 FFmpeg。Fontconfig 显式读取系统/LibreOffice 字体并使用本次任务缓存，避免打包运行库的构建路径造成中文缺字。

子进程使用 macOS sandbox-exec：禁止网络、只读系统/工具字体及依赖、仅写本次工作目录；环境变量重新构造，不传入数据库或微信密钥。进程组限制约 1GiB RSS、128 个进程、1500 秒 CPU、1GiB 输出文件和 1700 秒墙钟时间。守护进程退出和超时均清理子进程。

### Linux 自部署

构建 `scripts/meeting-material-preview/Dockerfile`：

```bash
docker build -t dianxinyun-material-preview:local scripts/meeting-material-preview
```

运行由转换脚本管理，禁网、只读根文件系统、丢弃 capabilities、非 root 用户，限制 1GiB 内存、1 CPU、128 进程、256MiB 临时目录，仅挂载本次工作目录。生产需预先构建/固定镜像、配置转换器绝对路径并核验中文字体和文件存储空间。本轮只交付当前 macOS 本地开发系统；Linux 镜像未完成构建验收，不代表已生产发布。
