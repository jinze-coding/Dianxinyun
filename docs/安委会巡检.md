Web 与小程序在附件预览中提供“向左旋转 90° / 向右旋转 90°”。每次点击直接保存，并显示已保存角度；可循环调整至 0/90/180/270°。已上传的暂存附件、本人记录的当前附件均可调整，关闭预览、返回列表、重新进入及另一端读取保持同一角度。平台管理员也可在查看他人当前附件时纠正方向；其他仅查看人员看到调整后的效果，不显示调整按钮，已移除的历史附件仍只读。

角度保存在附件上，独立于巡检表单提交。旋转不会提交未保存的分类/结论，也不改变检查人、首次提交时间或记录编辑版本。暂存文件随原上传用途检查新建/本人编辑权限，绑定记录后普通用户要求查看及本人修改权限；平台管理员可单独纠正方向，不因此获得他人巡检正文编辑权，也不能访问他人未提交的暂存附件。绑定后的每次实际角度变化写 `ATTACHMENT_ROTATE`，角度更新、派生文件退役和审计同事务。

`PUT /api/v1/safety-committee/attachments/{id}/rotation` 接收 `rotationDegrees / expectedVersion`；附件 DTO 返回 `rotationDegrees / rotationVersion / canRotate`。非法角度返回 400，版本冲突或历史附件返回 409，权限不足返回 403。保存期间防止重复点击，冲突后保留提示并读取当前角度，迟到响应不能覆盖新版本。

原件始终保留。服务端受限转换器从原件生成实际旋转后的 PNG（GIF 保留动画）、HEIF 的 JPEG 或 H.264/AAC MP4，原生全屏使用相同字节；普通图片回到 0° 时恢复原件预览。照片 EXIF 与视频显示矩阵先归正，再应用手动角度，避免重复旋转；视频行为参考 [FFmpeg 官方方向与自动旋转说明](https://ffmpeg.org/ffmpeg.html)。转换异步进行，界面提示“角度已保存，正在生成调整后预览”，失败可重试；过期工作任务不能发布到新角度。缩略图同样从原件生成，缓存包含角度版本。旧版本预览/缩略图读取凭证返回 409，视频 Range 不混用方向；读取原件沿用原资格。

普通角色必须通过系统管理明确授权，迁移不自动继承任何质量、电箱、临边或历史安全权限。菜单分配自动同步两个根菜单及记录页面，操作权限与菜单仍分开保存。平台管理员基于角色编码自动具备新模块及项目资格，无需写入项目成员或额外角色关系。

角色菜单分配的 `businessModuleCodes` 数量校验已同步为五个，允许同时保存场内、资料、巡检、质量和安委会；非法编码仍拒绝。修复仅调整请求校验，不修改任何已有角色授权。

后端从真实业务记录取得项目，检查当前有效账号、项目范围、模块和操作权限。上报和修改同时要求查看；编辑还要求记录检查人与当前用户相同。上传会话绑定用户、项目、新建键或本人编辑目标，完成后只能绑定本人的对应附件。通用文件接口不能枚举、读取、替换、换绑或删除 `COMMITTEE_INSPECTION_*` 文件，即使平台管理员也应使用专用接口。

关闭模块或撤权保留原细项配置，但业务请求被拒绝。读取 Cookie/不透明凭证不替代原登录，退出、凭证版本变化、账号/项目失效、模块或查看权限撤销均使后续读取及 Range 请求失效。客户端失权停止读取/上传并回个人待办或登录页。

## API

所有下列路径都位于 `/api/v1/safety-committee`。普通 JSON 响应复用现有 `Result` 包装，二进制接口直接返回媒体内容。普通接口需要 Authorization；无登录为真实 HTTP 401，无权限为 403。

| 方法与路径 | 请求及用途 |
| --- | --- |
| `GET /categories` | `projectId`，固定分类字典 |
| `GET /records` | `projectId`、可选 `category`、成对可选 `startDate/endDate`（YYYY-MM-DD）、`pageNo`；固定 20 条，返回 `records/total/latestId/serverTime` |
| `GET /records/{id}` | 记录详情、当前/历史附件、日志、`canEdit/canDelete` |
| `POST /records` | 新建；见下方示例 |
| `PUT /records/{id}` | 本人编辑；`category/conclusion/attachmentIds/expectedVersion` |
| `POST /uploads` | `projectId/draftKey/targetRecordId/fileName/totalSize/sha256`，创建上传会话 |
| `GET /uploads/{session}` | `projectId`，读取会话及已完成分片序号 |
| `PUT /uploads/{session}/chunks/{index}` | `projectId`，multipart 的 `chunk/sha256`；index 从 0 开始 |
| `POST /uploads/{session}/complete` | `projectId`，校验合并并返回暂存附件；重试返回同一附件 |
| `DELETE /uploads/{session}` | `projectId`，取消未完成会话及分片 |
| `GET /attachments/{id}` | 原文件信息、预览状态、错误提示 |
| `DELETE /attachments/{id}` | 丢弃本人未绑定暂存附件 |
| `POST /attachments/{id}/preview-retry` | 原作者或管理员重试失败预览，记录操作 |
| `POST /attachments/{id}/thumbnail` | 可选 `retry`，请求缩略图并返回生成状态；不改变记录绑定 |
| `POST /attachments/{id}/read-session` | Web 默认写 HttpOnly Cookie；`nativePlayback=true` 返回小程序读取路径和过期时间 |
| `GET/HEAD /attachments/{id}/content` | Cookie 或原登录鉴权，`preview=true` 预览，false 下载原件，支持 Range；`thumbnail=true` 读取 JPEG 缩略图 |
| `GET/HEAD /media/{opaqueCode}` | 原会话和附件绑定读取，`preview/thumbnail` 同上，15 分钟有效 |

日期按北京时间 `inspected_at >= startDate 00:00:00` 且 `< endDate 次日 00:00:00` 查询，覆盖 `DATETIME(6)` 的日末微秒；数据库最大日期 9999-12-31 使用最大有效微秒上界。日期支持 1000-01-01 至 9999-12-31，缺一项、倒序、非法格式返回 HTTP 400。无日期参数的旧客户端行为不变。分页、总数、`latestId` 复用同一条件及现有项目/分类/检查时间索引，无数据库迁移或新增权限。

新建示例（检查人和时间不属于可写字段）：

```json
{
  "projectId": 3,
  "category": "其他",
  "conclusion": "",
  "attachmentIds": [],
  "requestKey": "b866c50994db4fd99e6f065e6e77636e"
}
```

`requestKey` 与项目、作者唯一绑定，保存请求摘要；相同重试返回原记录，键相同但内容变化为 HTTP 409。编辑整条记录使用 `expectedVersion`，冲突返回 409，客户端保留输入供核对。附件越权或用途不匹配拒绝；记录、附件绑定与操作日志同事务，任何一步失败整体回滚。

管理员删除使用已有 `/api/v1/system/deletions/preview` 和 `/execute`，`targetType=COMMITTEE_INSPECTION`。预览包括当前/历史附件、所有预览副本、日志和文件字节；令牌包含当前版本/影响，过期或影响变化拒绝。项目删除影响与级联纳入三张新表。删除检查人保留历史记录、姓名快照和审计。

## 附件、转换与读取

限制均按二进制 MiB，服务端独立执行扩展名、大小、文件头和 Office 容器校验，不扩展其他业务模块的文件策略。

| 类型 | 最大文件大小 | 支持格式 |
| --- | --- | --- |
| 图片 | 15 MiB | JPG/JPEG、PNG、GIF、BMP、WebP、HEIC/HEIF |
| 视频 | 500 MiB | MP4、MOV、M4V、WebM、MKV、AVI |
| 办公文件 | 100 MiB | PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、WPS/ET/DPS、RTF、TXT、CSV |

两端采用 8 MiB 分片和 SHA-256，合并后再次检查总大小与整文件摘要。会话 24 小时有效，状态包含已收分片；选中的文件若失败或暂停则禁止保存，必须重试续传或明确移除。小程序读取文件使用 `position/length`，单次最多 8 MiB，不把整段 500 MiB 视频读入内存。客户端续传缓存按用户/项目/用途隔离。

文件类型分别为 `COMMITTEE_INSPECTION_PENDING / ATTACHMENT / PREVIEW`。附件状态 `PENDING → ACTIVE → HISTORICAL`；未绑定附件到期清理，历史附件随记录保留。预览状态 `WAITING → QUEUED → PROCESSING → READY/FAILED`，普通栅格图可直接 READY；失败保留原件、原因和重试入口。工作租约防止多次生成，进程重启后可恢复过期任务。

复用 `scripts/meeting-material-convert.sh` 的受限转换器及环境配置：Office 转 PDF、HEIF 转 JPEG、视频转 H.264/AAC MP4。转换在独立临时目录及既有资源/网络限制下异步运行，原文件不变。文件保存注册事务回滚清理；删除先更新元数据，提交后物理删除，清理失败保留可追踪状态；重试替换掉的预览副本也包含在管理员删除中。

Web 的读取 Cookie 为 HttpOnly、SameSite=Strict、限定附件 content 路径，HTTPS 时 Secure。小程序使用随机不透明凭证，Redis 只存摘要索引，15 分钟及原 JWT 到期时间取较早者。读取 URL 没有 JWT，二进制响应 `private, no-store`、`nosniff`，下载原件使用 attachment；预览仅返回安全图片/PDF/MP4。每个 Range 请求重新鉴权，支持浏览器/微信视频拖动。

关闭预览停止播放、轮询和未完成下载。Web 支持保存文件流，兼容浏览器使用可取消的有界 Blob 下载；小程序保留原生文档打开期间的临时文件，返回恢复原页面，关闭后清理。原生不支持直接打开的原件可由用户点击导出，图片/视频可保存相册。
