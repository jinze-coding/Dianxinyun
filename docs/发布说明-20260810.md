# 2026-08-10 阿里云生产更新包说明

本说明对应 `Dianxinyun-production-update-20260810.tar.gz`。压缩包只用于上传到已确认的阿里云
主机，不会自动修改数据库、切换软链接、重启服务或覆盖生产配置。

## 包内内容

- `backend/site-platform.jar`：Java 17 / Spring Boot 后端生产 JAR；
- `frontend/`：以 `/api/v1` 为接口前缀构建的 Web 静态文件；
- `migrations/`：从统一注册/RBAC 到项目档案的正式增量 SQL，不含 `init.sql` 和测试夹具；
- `PRECHECK.sql`：只读生产预检，检查迁移标记、菜单层级、权限和项目档案结构；
- `SOURCE_MANIFEST.txt`：源码分支、提交、工作区状态、工具版本和构建结果；
- `source/`：本次构建所用当前源码的不可变归档，不含 `.git`、依赖目录、构建目录和私密环境文件；
- `ARTIFACTS.sha256`：包内交付物校验和。

## 本次权限修复

角色操作权限改为按“一级菜单 → 二级页面/跨页通用操作 → 页面动作”展示。对于只存在部分二级
菜单的数据库，前端不再把缺失页面伪装成旧库兼容页，也不会让管理员勾选后端必然拒绝的权限。

截图中的 `操作权限不属于已分配菜单：document.view` 还对应一个数据库混合迁移状态：若生产库
已有 `DOCUMENT_SEAL` 或 `INSPECTION_RECTIFICATIONS`，却缺少
`DOCUMENT_LIBRARY / DOCUMENT_RECYCLE / INSPECTION_LEDGER / INSPECTION_RECORDS /
QUALITY_ISSUES / QUALITY_DOCUMENTS` 或迁移标记
`20260803_ROLE_MENU_PERMISSION_HIERARCHY_V1`，必须先执行包内
`20260803_role_menu_permission_hierarchy.sql` 并核对结果。

## 执行边界

1. 上传后先校验外层 SHA-256，再解压并校验 `ARTIFACTS.sha256`。
2. 先执行 `PRECHECK.sql`，根据结果确认缺失迁移；禁止直接把 `migrations/` 全部批量执行。
3. 禁止执行 `init.sql`、空库初始化模板或测试夹具。
4. 数据库迁移、JAR 切换、Web 软链接切换和服务重启必须分别验收；任何一步失败立即停止。
5. 真实 `.env`、数据库密码、JWT/微信/访客/用印密钥不在包内，继续使用服务器受控配置。
6. 阿里云的实际目录、服务名、运行用户和 Nginx 配置以服务器只读检查为准，不凭本说明猜测。

完整安全要求和回滚条件见包内 `生产升级与回滚手册.md`。
